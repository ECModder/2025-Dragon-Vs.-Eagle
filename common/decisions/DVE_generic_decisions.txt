# ============================================================
#   DvE - Generic Decisions: Domestic Affairs, Military Affairs
#   and Foreign Relations
#
#   Universal decisions available to every country regardless of
#   its own focus tree. Names/costs are taken verbatim from the
#   reference screenshots; instant "for N days" effects use the
#   timed ideas in common/ideas/DVE_generic_decisions_ideas.txt,
#   while "after N days" effects fire a delayed one-shot event
#   from events/DVE_generic_decisions_events.txt. Categories are
#   defined in common/decisions/categories/
#   DVE_generic_decisions_categories.txt.
# ============================================================
