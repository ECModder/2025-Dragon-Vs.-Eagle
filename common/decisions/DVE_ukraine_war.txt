# ============================================================
#   DvE - LA GUERRA D'UCRAINA
#
#   Struttura copiata dalla guerra italo-etiope del gioco base:
#   una missione col conto alla rovescia piu' una scala di
#   obiettivi, tutti visibili nella stessa categoria.
#
#   Gli obiettivi sono missioni con selectable_mission = no: si
#   completano DA SOLE appena la condizione e' vera, senza che il
#   giocatore clicchi niente, e intanto restano in elenco. E' lo
#   stesso meccanismo di "Hold the North" in Etiopia.
#
#   Proprio per questo non serve piu' agganciarsi a
#   on_state_control_changed: le missioni si controllano da sole.
#
#   RUSSIA   Donbass -> Odessa -> Kiev
#   UCRAINA  Donbass -> Crimea -> oltre confine
# ============================================================
