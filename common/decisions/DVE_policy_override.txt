# ============================================================
#   DvE - Better Laws and Policies: manual override, 350pp
#
#   Every one of these 11 law groups is ideology-locked
#   (common/scripted_effects/DVE_state_policies_effects.txt sets
#   the correct tier automatically, and each tier's own
#   "available" blocks manual selection in the normal law
#   panel). This is the only way around that: pay 350pp, get
#   whichever tier you pick, no matter what your government
#   would otherwise assign. Repeatable - nothing stops paying
#   again later for a different tier, or to undo this one.
#
#   One decision per tier (50 total), each hidden once you
#   already have that tier via "NOT = { has_idea = X }".
# ============================================================
