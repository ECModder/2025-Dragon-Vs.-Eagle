	# ============================================================
	#   Economic Model - locked to ideology, not player-selectable.
	#
	#   Every tier's "available" requires the one specific
	#   government it belongs to, so the normal law panel never
	#   offers a real choice - whichever tier matches your current
	#   government is the only one ever selectable there. The
	#   actual assignment is automatic, done by
	#   DVE_set_economic_model_effect (common/scripted_effects/
	#   DVE_state_policies_effects.txt), called once for every
	#   country on_startup and again from on_ruling_party_change
	#   whenever a government changes.
	#
	#   The two exceptions: revolutionary_socialism starts on
	#   Syndicalist Economy and vanguard_socialism starts on
	#   Socialist Economy, each upgradable ONCE for 300pp via
	#   common/decisions/DVE_state_policies.txt. Socialist Economy
	#   is therefore reachable two ways - as vanguard_socialism's
	#   own base, or as revolutionary_socialism's paid upgrade -
	#   which is why its availability checks a flag on one side and
	#   nothing on the other.
	# ============================================================
