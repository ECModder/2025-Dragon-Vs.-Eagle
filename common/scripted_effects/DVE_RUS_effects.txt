# ============================================================
#   DvE - la fine della Russia
#
#   Due effetti, in sequenza cronologica.
#
#   1) RUS_lost_war_settlement_effect
#      Il trattato che chiude la guerra d'Ucraina quando finisce
#      male (sconfitta o pace bianca): Kursk e Belgorod all'Ucraina
#      insieme ai territori occupati nel 2022 e alla Crimea,
#      Sachalin e Curili al Giappone, Kaliningrad all'ONU.
#      Va chiamato dall'evento di fine guerra, PRIMA di caricare
#      l'albero post-sconfitta.
#
#   2) RUS_second_civil_war_effect
#      Il timeout della crisi di successione
#      (common/decisions/RUS_succession_crisis.txt).
#
#   PERCHE' NON start_civil_war
#   start_civil_war accetta ideology/size/states/capital ma NON un
#   tag: creerebbe nazioni dinamiche (D01, D02...) invece di SOV,
#   RUR e NRE. Qui i tag vengono attivati davvero, ricevono
#   territorio e cores e dichiarano guerra.
#
#   SPARTIZIONE (confini esatti dati dai dev)
#     SOV "RSR" - Tver, Pskov, Novgorod, Leningrado, Carelia,
#                 Murmansk, Daghestan, Volgograd, Saratov, Perm,
#                 Mordovia, Chuvascia, Tatarstan, Udmurtia,
#                 Chelyabinsk, Bashkortostan, Tuva, Buriazia,
#                 Irkutsk, Penza, Ulyanovsk, Voronezh
#     RUR "RDR" - Sverdlovsk, Kurgan, Tyumen, Jugra, Jamalia,
#                 Krasnojarsk, Khakassia, Altai
#     NRE "RUE" - Jacuzia, Magadan, Chukotka, Kamchatka,
#                 Khabarovsk, Primorye, Oblast ebraica, Amur
#     KUB       - Krasnodar
#     KAL       - Kalmykia
#     CIN       - Cecenia-Inguscezia (gia' sua) + Kabardino-Balkaria
#     RUS       - tutto il resto
#
#   NOTA: il tag KAM (Kamchatka) resta definito ma non viene piu'
#   usato: la Kamchatka e la Chukotka vanno a NRE.
#
#   Governo, popolarita' e stabilita' di SOV/RUR/NRE NON vengono
#   forzati qui: restano quelli dei rispettivi file in
#   history/countries/, cosi' basta modificare quelli.
# ============================================================
