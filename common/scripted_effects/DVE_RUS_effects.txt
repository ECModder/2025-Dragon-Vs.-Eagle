# ============================================================
#   DvE - la fine della Russia
#
#   Due effetti, in sequenza cronologica.
#
#   1) RUS_lost_war_settlement_effect
#      Il trattato che chiude la guerra d'Ucraina quando finisce
#      male (sconfitta o pace bianca). Nascono le tre zone
#      smilitarizzate della mappa: Belgorod all'Ucraina, Sachalin
#      al Giappone, Kaliningrad sotto amministrazione ONU.
#      Va chiamato dall'evento di fine guerra, PRIMA di caricare
#      l'albero post-sconfitta.
#
#   2) RUS_second_civil_war_effect
#      Il timeout della crisi di successione
#      (common/decisions/RUS_succession_crisis.txt). Il paese si
#      spacca in cinque e le repubbliche caucasiche se ne vanno.
#
#   PERCHE' NON start_civil_war
#   start_civil_war accetta ideology/size/states/capital ma NON un
#   tag: creerebbe nazioni dinamiche (D01, D02...) invece di SOV,
#   RUR, NRE e KAM. Qui i tag vengono attivati davvero, ricevono
#   territorio e cores e dichiarano guerra.
#
#   SPARTIZIONE (dalla mappa della guerra civile)
#     RUS - Mosca, centro e nord-ovest europeo
#     SOV - "RSR", la fascia socialista: sud europeo, basso Volga,
#           Urali meridionali e Siberia meridionale
#     RUR - "RDR", Siberia occidentale e centrale
#     NRE - "RUE", Siberia settentrionale, Jacuzia, Estremo Oriente
#     KAM - Kamchatka e Chukotka
#     Indipendenti: KUB, KAL, DAG, NOA, CIN
#
#   Governo, popolarita' e stabilita' di SOV/RUR/NRE NON vengono
#   forzati qui: restano quelli dei rispettivi file in
#   history/countries/, cosi' basta modificare quelli.
# ============================================================
