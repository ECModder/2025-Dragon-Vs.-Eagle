# ============================================================
#   DvE - GENERIC FOCUS TREE (2025)
#
#   Same layout as the vanilla generic tree, rebuilt for DvE:
#     INDUSTRIAL EFFORT  free civilian/military factories with
#                        their building slots, infrastructure,
#                        resource discovery, 4th and 5th research
#                        slot (max 5 slots from this tree)
#     ARMY EFFORT        army XP, land doctrine, infantry/artillery/
#                        support/armour bonuses, conscription
#     NAVAL EFFORT       free dockyards, light (subs/destroyers) or
#                        heavy (cruisers/capital ships) hulls
#     AIR EFFORT         air bases, fighters, bombers, CAS, naval
#                        aviation, missiles and jets
#     POLITICAL EFFORT   4 mutually exclusive blocs, one branch for
#                        each of the 14 DvE ideology groups. Every
#                        branch has 15 focuses, modelled on the post-
#                        civil-war trees of INT/SOV/CSR:
#                          movement -> take power (puts the group in
#                          government; needs 35% support or the group
#                          already ruling) -> congress -> two mutually
#                          exclusive internal currents -> security
#                          chain, ideology spirit + institution,
#                          propaganda chain -> influence abroad,
#                          ideology end, ideological bloc -> capstone
#
#   ACTIVE ONLY FOR: AUS (Austria), for testing. add = 100 beats
#   vanilla austria.txt (add = 50). To roll it out, change the
#   country = {} block below.
#
#   Spirits: common/ideas/DVE_GEN_spirits.txt
#   Opinion: common/opinion_modifiers/DVE_GEN_opinion_modifiers.txt
#   Text:    localisation/english/GEN_focus_l_english.yml
#   All focuses cost 5 (35 days); icons are vanilla generic ones.
# ============================================================
