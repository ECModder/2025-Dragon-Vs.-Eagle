# ============================================================
#   THE INTERNATIONALE (INT) - albero nazionale
#
#   Nasce dalla guerra civile italiana: il ramo "Lotta Comunista"
#   dell'Italia (common/national_focus/italy.txt), tutto cio' che
#   viene dopo "Coup de Main" (LT_coup). Le radici dell'albero -
#   LT_staterev (Rivoluzione di Stato, revolutionary_socialism) e
#   LT_international (L'Internazionale, vanguard_socialism) -
#   in Italia avevano "prerequisite = { focus = LT_coup }" (o
#   LT_warrev); quel prerequisito e' stato tolto qui perche' punta
#   a un focus che ora appartiene all'albero di un altro paese
#   (ITA) - una volta che l'INT esiste, il colpo di stato e' gia'
#   avvenuto per definizione.
#
#   NOTA: questo file sposta solo l'albero. Il meccanismo che
#   davvero fa scoppiare la guerra civile e trasforma ITA in INT
#   (change_tag / form_new_country dal completamento di LT_coup)
#   non e' ancora stato scritto.
#
#   54 focus, identici a com'erano in italy.txt salvo le coordinate
#   x/y (traslate per ripartire da un'origine pulita) e i due
#   prerequisiti tolti sopra.
# ============================================================
